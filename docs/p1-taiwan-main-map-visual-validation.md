# P1 台灣主航海圖視覺驗證

## 驗證範圍

已於開發預覽的 `/map` 路由檢視 **375px × 812px** 與 **1280px × 960px** 畫面。

| 檢查項目 | 結果 | 觀察 |
| --- | --- | --- |
| 台灣方位辨識 | 通過 | 北部國語、中部數學、南部社會與東部自然以卡片與島形輪廓清楚區隔。 |
| 桌面資訊層級 | 通過 | 主航海圖置於今日導引／觀測進度之後、學生關係圖之前，符合先選學科再延伸探索的閱讀順序。 |
| 375px 版面 | 通過 | 航海圖縮放後保持四科卡片可讀，未出現水平捲動或文字與按鈕重疊。 |
| 空資料降級 | 通過 | 畫面使用「等待第一次探索」等正向文字，未呈現虛構完成度或負面標籤。 |

## 備註

本次檢視的預覽資料沒有近期作答紀錄，因此未展開真實知識點面板；該互動已由元件回歸測試覆蓋。後續可用具有作答紀錄的帳號再次手動檢視面板高度與快速複習入口。
