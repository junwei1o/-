# 戰鬥系統第 5 階段驗證紀錄

本次驗證以正式 RPG 戰鬥核心、有限狀態機與正式題庫流程為準，不建立假題庫或替代戰鬥規則。

| 驗證面向 | 方法 | 已確認結果 |
| --- | --- | --- |
| 自動戰鬥 | `runBattleSimulations(100)` | 100 場確定性戰鬥均完成，並檢查生命值、終局與狀態機回到 `IDLE`。 |
| 邊界情境 | 模擬器回歸測試 | 覆蓋連勝、恢復型答題、三連擊暴擊、守門者干擾、玩家 HP 歸零與無效次數降級。 |
| 375px 題目操作 | JSDOM + 瀏覽器實機流程 | 四個選項在兩欄格線內呈現；每個選項保有最少 58px 高度與長文字換行空間。 |
| 行動控制 | 375px 瀏覽器實機流程 | 基礎攻擊、必殺與超必殺均可見、可點選，且不與頂端導覽重疊。 |

> 這份紀錄描述測試範圍與觀察結果；發布前仍須執行完整 Vitest、TypeScript 檢查及 production build。
