# 台灣主航海圖：地圖與 UI 融合評估

## 結論

目前的「我的地圖」已經不是單純裝飾，而是可用的學習導航入口。它已具有四科真實資料快照、島嶼點按面板、學科練習與近期知識點複習入口；因此下一輪最有效的工作，不是重做地圖引擎，而是把這些已存在的行為收束成更有「寶島航海」感的首頁式主畫面。

> **建議方向：** 保留現有 SVG + CSS 的輕量架構，將「台灣主航海圖」升級為第一個學習入口；同時以「學習旅程狀態」取代以正確率高低標籤學生的三色系統。

## 目前實作現況

| 核對項目 | 目前情況 | 對下一步的意義 |
|---|---|---|
| 地圖繪製 | `TaiwanMainNavigationMap` 以內嵌 **SVG** 畫出海面、台灣輪廓、航線和錨點，外觀由元件 CSS 控制。 | 目前不需要改用 Canvas、PixiJS 或 Leaflet；SVG 仍可精準控制四個節點與鍵盤語意。 |
| 節點來源 | 四座島嶼的位置由固定的學科中繼資料定義；每座島的解鎖、近期知識點和提示內容，則由 `islandSnapshots` 的真實作答資料帶入。 | 「位置手動、狀態動態」是合適的 P1 設計：台灣地理不會跳動，學生資料才會改變。 |
| 目前流程 | 學生可在 `/map` 點選學科島，開啟面板後進入整科練習或某個近期知識點的複習。 | 已經符合「選島 → 看面板 → 開始練習」，不應改成點選後立即跳題。 |
| 預設首頁 | 目前網站根路徑仍保留既有首頁；主航海圖是「我的地圖」頁面，而非預設首頁。 | 「地圖即首頁」可作為下一輪最有感的導覽改造，但應保留原首頁作為世界觀／新手入口。 |
| 科目與區域 | 目前有 **國語、數學、社會、自然** 四科，而非英文；主航海圖已採台灣方位配置。 | 應以現有四科建立區域意象，不能將南部改成尚未有真實題庫入口的英文港。 |

目前桌面版已呈現暖白紙張背景、藍綠海面、淡色台灣輪廓與四張學科島卡。主航海圖下方仍保留「以我為中心的學習拼圖」，兩者可形成清楚的層次：上層回答「下一站去哪裡」，下層回答「這些學習和我有什麼關係」。

## 對三色狀態系統的調整建議

以「高／中／低正確率」決定金、綠、橘，會使孩子把橘色理解成失敗標籤，也會讓求助紀錄與掌握程度混在一起。這與目前專案的正向回饋原則不一致。因此建議保留你提出的視覺節奏，但改由**真實且不評斷學生的學習旅程狀態**驅動。

| 建議狀態 | 真實資料條件 | 視覺語言 | 面板文案範例 | 不應顯示 |
|---|---|---|---|---|
| 準備啟程 | 該學科尚無作答紀錄 | 淡霧、灰藍輪廓、未展開小旗 | 「第一張航圖正在等你留下記號。」 | 「落後」、「0%」、「待加強」 |
| 正在探索 | 該學科已有一筆以上真實作答或近期知識點 | 玉山綠航標、柔和海面脈動 | 「你已經留下探索記錄，可從最近的知識點接著走。」 | 錯題數、連續答錯提示 |
| 航線延伸 | 該學科已有可呈現的近期複習軌跡，或由既有資料安全判定為已解鎖 | 金色旗幟、開啟的航線短段、低干擾光點 | 「這條航線已展開，下一站可以自行選擇。」 | 「高正確率」、「完美」等壓力語言 |

橘色仍可保留，但應作為中性行動提醒，例如「有一個最近接觸的主題可回來看看」，而非依低正確率標記整座島。若未來需要顯示掌握概況，應放在面板細節內，以「正在建立理解」與具體下一步呈現，並與求助習慣分開。

## 台灣意象與現有四科的對應

| 台灣區域 | 已有學科 | 建議地景與圖示 | 可沿用的既有資料入口 |
|---|---|---|---|
| 北部文化城 | 國語 | 古城門、毛筆、書卷、暖金小旗 | 國語學科練習與近期知識點 |
| 中部測量原野 | 數學 | 幾何田畝、量尺、齒輪、格線航標 | 數學學科練習與近期知識點 |
| 南部港灣群島 | 社會 | 港口、燈塔、航線、地方文化印記 | 社會學科練習與近期知識點 |
| 東部山海觀測站 | 自然 | 山脈、浪線、望遠鏡、顯微鏡 | 自然學科練習與近期知識點 |

南部港灣可以保留「國際感」，但目前應以社會科的地理、歷史與公民脈絡呈現。等英文題庫與對應入口真正建立後，才能把英文另設為外海港或跨島支線；這樣可避免視覺功能超前於真實學習內容。

## 建議的首頁與面板版面

首頁不必刪除既有的學習推薦或學生關係地圖，而是將主航海圖移到最前方。桌面版可讓主航海圖佔據第一個主要區塊；手機版則先呈現「今日從哪條航線開始」短卡，再呈現可橫向閱讀的台灣圖與選取面板。

```text
┌─────────────────────────────────────────────────────┐
│ 頂部 HUD：名稱、等級、我的地圖、設定                │
├─────────────────────────────────────────────────────┤
│ 今日航線短卡：建議從哪科開始（只依真實資料）        │
├──────────────────── 台灣主航海圖 ───────────────────┤
│        [北部：國語城]                                │
│                 ──航線──                            │
│          [中部：數學原野]                            │
│                              [東部：自然觀測站]      │
│                    [南部：社會港灣]                  │
│                                                     │
│  點選後：毛玻璃資訊面板                              │
│  島名／旅程狀態／真實近期知識點／兩個膠囊按鈕        │
├─────────────────────────────────────────────────────┤
│ 以我為中心的學習拼圖、生活連結線與其他探索入口      │
└─────────────────────────────────────────────────────┘
```

毛玻璃卡可使用暖白半透明底色、`backdrop-filter: blur(10px)`、深墨綠文字與清楚邊框。不應用透明度犧牲閱讀；在 `prefers-reduced-motion` 或不支援 blur 的環境中，卡片必須退回不透明暖白底色。兩個主要膠囊按鈕應保留「從這座島開始」與「查看近期知識點」，避免把「錯題重練」放在第一層造成壓力。

## 分期實作決策

| 優先級 | 範圍 | 建議技術 | 驗收重點 |
|---|---|---|---|
| P1.1 | 將主航海圖升為首頁首要區塊，保留既有首頁為新手／世界觀入口 | Wouter 路由調整 + 現有 React 元件重排 | 開站後可立即看到航海圖；所有既有 `/map` 深連結仍可用。 |
| P1.2 | 加入三種「旅程狀態」與區域台灣意象 | 擴充現有 SVG 節點 class 與 CSS token | 狀態只從真實快照得出；無資料時維持正向空狀態。 |
| P1.3 | 將航線改成會隨狀態畫出的短段 | SVG `stroke-dasharray` / `stroke-dashoffset` + CSS transition | 動畫 180–240ms；reduced-motion 下顯示靜態已畫好航線。 |
| P2 | 每日補給站、角色移動、成就慶祝 | 必須先定義真實資料、每日重置與獎勵規則 | 不建立虛構獎勵；每日功能需另行設計可用的排程與資料持久化。 |
| 暫緩 | Panzoom、Canvas/PixiJS、Lottie 粒子 | 不新增依賴 | 四個節點的 P1 地圖不需要複雜地圖引擎，優先確保閱讀、觸控與內容導向。 |

## 建議立即開始的三項改造

第一項是將 `TaiwanMainNavigationMap` 移到首頁最前方，讓學生進入後先看到「去哪裡學」，再看到其他儀表板與關係地圖。第二項是將節點樣式升級為「準備啟程／正在探索／航線延伸」，並把現有近期複習資料放進毛玻璃面板。第三項是將目前的虛線航路升級為狀態控制的 SVG 描邊動畫；這項效果成本低，也最能帶出航海圖的前進感。

在完成這三項前，不建議先做隨機補給箱、煙火或角色移動。它們需要持久化、日更規則和更完整的獎勵設計，若過早加入，容易讓學習導航被裝飾性的互動稀釋。
