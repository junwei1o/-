# 台灣課綱互動學習遊戲

將教育遊戲需求拆成可驗證的題庫資料、抽題規則、學習紀錄、報告視覺化與前端交付流程。優先使用現有專案的資料模型與元件，不要在沒有盤點狀態欄位前重寫答題流程。

## 標準工作流

1. **盤點專案**：讀取題目型別、題庫常數、篩選 state、答題函式、計時器、localStorage helper、錯題本與學習報告。確認是否為 React 靜態前端；除非使用者明確要求，勿修改 backend。
2. **建立待辦**：在專案 `todo.md` 加入未勾選項目，涵蓋資料結構、抽題、畫面、驗證與交付。完成每一階段後更新勾選狀態。
3. **定義題目 schema**：每題至少包含 `id`、`grade`、`subject`、`difficulty`、`prompt`、`options`、`answer`、`explanation`、`knowledge`、`curriculumDomain`、`learningTopic`、`learningPerformance`、`learningContent` 與 `competency`。保留固定 id，供錯題本與報告追蹤。
4. **對應台灣課綱**：依年級與科目填入課綱領域、學習主題、學習表現、學習內容及核心素養。將課綱來源與對應原則記錄在專案文件；不要把不確定的官方代碼當成已核實資料。
5. **建立篩選**：提供年級、科目、難度與課綱領域篩選。篩選後先產生候選集合，再進入隨機抽題；空集合必須顯示可理解的空狀態與重設按鈕。
6. **實作隨機抽題**：使用 Fisher–Yates 洗牌或等價方法。未指定科目時，若候選題目足夠，先從數學、自然、社會、國語各取至少一題，再以洗牌後的候選題補齊；若某科沒有符合篩選條件，勿製造假題，改以實際可用題目抽取。
7. **整合計時器**：開始新題前先清除舊 interval；離開挑戰、完成作答、切換題目與重新套用篩選時清理計時器。逾時只能結算一次，並將題目加入錯題紀錄。
8. **保存篩選與紀錄**：用版本化的 localStorage key 保存篩選條件與學習狀態。載入時解析 JSON、驗證 enum 與數值範圍、合併預設值；損壞或過期資料回退，不得讓初始化崩潰。保存與恢復以短暫 Toast 回饋，但初始化不可重複提示。
9. **顯示解析與課綱**：答題後顯示詳細解析、知識點標籤及課綱學習重點。使用 `textContent` 或 React JSX 輸出使用者輸入，避免將筆記或外部資料直接插入未轉義的 `innerHTML`。
10. **建立學習報告**：以實際答題紀錄計算答題量、整體正確率、科目正確率、知識點掌握與課綱領域掌握。答錯或逾時後要從答對集合移除，避免正確率高估；未作答領域顯示「—」或空白，不視為 0 分。
11. **選擇圖表**：家長與手機使用情境優先採用水平長條圖；需要比較多維輪廓時才加入雷達圖。圖表旁提供文字摘要、作答量與計算口徑，並使用 `role="img"`、`aria-label` 或等價無障礙資訊。
12. **驗證與交付**：執行 TypeScript 檢查；截取桌面與手機代表畫面；測試篩選、重設、隨機重抽、計時逾時、空題組、本機恢復、報告空資料與實際答題後的統計。完成後更新 `todo.md`，建立單一完整 checkpoint 再交付。

## 資料與統計規則

- 將 `completed`、`wrong` 與 `answered` 視為不同概念。`answered = completed ∪ wrong`，避免同一題重複計算。
- 正確率為 `correct / answered`，沒有作答時顯示未作答，不要顯示誤導性的 0%。
- 知識點可由每題的 `knowledge` 陣列聚合；同一題含多個標籤時，每個標籤都累計該題一次。
- 課綱領域統計必須使用題目上的 `curriculumDomain`，不要由科目名稱臨時猜測。
- 報告只讀取本機資料時，明確顯示隱私提示；不要宣稱資料已同步到雲端。

## UI 與安全守則

- 延續既有品牌設計，新增圖表應像探險誌的觀測記錄，而不是無層次的管理後台。
- 手機版圖表使用可換行的領域名稱、足夠對比與不依賴顏色的文字百分比。
- 支援 `prefers-reduced-motion: reduce`，圖表動畫只使用 transform、opacity 或短暫寬度過渡。
- 所有按鈕與 select 都要可鍵盤操作，焦點狀態清楚。
- 對筆記、題目文字與報告內容避免不安全的 HTML 拼接；若必須使用 HTML，先進行 escape 或改用 DOM/JSX。
- 不要產生虛假的學生、家長、教師評語、評分或 testimonial；報告內容只能來自實際本機紀錄。

## 參考來源

台灣課綱分類與領綱文件應以國家教育研究院的官方課綱頁面為查核起點：[國家教育研究院十二年國民基本教育課程綱要](https://www.naer.edu.tw/PageSyllabus?fid=52)。若要填入正式學習重點代碼，先讀取對應領綱原文並保存來源與版本日期。
