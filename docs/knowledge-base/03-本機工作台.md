## 本機端對端驗證（測登入閘／權限閘時必備）

```bash
NODE_ENV=development PORT=3000 \
  JWT_SECRET=local-secret VITE_APP_ID=local-app \
  ADMIN_PASSPHRASE=local-admin TEACHER_PASSPHRASE=local-teacher \
  node node_modules/tsx/dist/cli.mjs server/_core/index.ts
```

**四個都不能少，埠必須 3000**：

| 條件 | 不給會怎樣 |
| --- | --- |
| `VITE_APP_ID` | 登入回 `ok:true`，但 `admin.me` 永遠 `isAdmin:false` |
| `PORT=3000` | 非標準埠走 http 會被 CSRF Origin 守衛擋掉**所有** mutation |
| `ADMIN_PASSPHRASE` | 後台顯示「尚未啟用」 |
| `JWT_SECRET` | session token 簽不出一致 |

## 部署

| 項目 | 值 |
| --- | --- |
| 平台 | Render（`render.yaml`） |
| 建置指令 | `pnpm install --frozen-lockfile` → 裝 edge-tts → `pnpm build` |
| 啟動指令 | `pnpm start`（`node dist/index.js`） |

> ⚠️ **`--frozen-lockfile` 是硬約束**：`package.json` 與 `pnpm-lock.yaml`
> 不同步會**直接讓部署失敗**。任何加依賴的動作都必須同時更新 lockfile。

## 環境變數

| 變數 | 必要性 | 用途 |
| --- | --- | --- |
| `DATABASE_URL` | 建議 | 雲端存檔、班級、公告、試卷紀錄。**未設則全站退回 localStorage** |
| `JWT_SECRET` | **必須** | session 簽章；生產未設會拒絕啟動 |
| `ADMIN_PASSPHRASE` | 後台必須 | 站長登入。**不可與教師通關語相同** |
| `TEACHER_PASSPHRASE` | 督學台必須 | 教師登入 |
| `VITE_APP_ID` | **必須非空** | 會話 payload 的一部分，空值會讓「登入成功但閘門永不通」 |
| `GROQ_API_KEY` | AI 建議 | AI 主要供應商 |
| `CEREBRAS_API_KEY` / `DEEPSEEK_API_KEY` | 選填 | AI 備援供應商（任一或多個都加，多一路保險） |
| `LINE_CHANNEL_SECRET` / `LINE_CHANNEL_ACCESS_TOKEN` | LINE 選填 | LINE 通知與推播 |

> ⚠️ **`VITE_` 前綴 = 公開。** Vite 會把所有 `VITE_` 變數內聯進前端 bundle。
> 機密（通關語／JWT／DB／LLM key）**絕對不可**用此前綴。

## 憑證衛生

曾經有 3 個 clone 的 git remote URL 內嵌明文 PAT，已全部清除並改用
`credential.helper=osxkeychain`。**複檢指令**：

```bash
find /Users/g -maxdepth 7 -name config -path "*/.git/*" -exec grep -lE 'ghp_|x-access-token' {} \;
```

也要檢查 `~/.gitconfig`、`~/.git-credentials`、`~/.zsh_history`。

⚠️ **兩種 URL 形式都要搜**：`https://x-access-token:ghp_…@` 與 `https://ghp_…@`
——只搜其中一種會漏。
