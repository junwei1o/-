# 天文館內容校對來源

## NASA Solar System Exploration
來源：https://science.nasa.gov/solar-system/

NASA 頁面指出太陽系包含太陽、八大行星、五個正式命名的矮行星、數百個衛星，以及大量小行星與彗星；太陽系位於棒旋星系銀河系的獵戶座支臂附近。頁面也提供行星、衛星、小行星與彗星、觀星等學生友善主題，可作為太陽系與觀測展區的內容基礎。

## NASA Black Hole Basics
來源：https://science.nasa.gov/universe/black-holes/

黑洞不是傳統意義的洞，而是物質被壓縮在極小空間形成的高密度天體；事件視界是光也無法逃逸的邊界。黑洞本身不發光，科學家會透過吸積盤的 X 射線、附近恆星的運動、重力波與重力透鏡等周邊效應間接研究它。NASA 也強調黑洞不是蟲洞，也不是會吸走遠方一切物質的宇宙吸塵器。

## NASA 黑洞學生版（Grades 5-8）
來源：https://www.nasa.gov/learning-resources/for-kids-and-students/what-is-a-black-hole-grades-5-8/

學生版資料適合轉寫為分層學習內容：黑洞可依質量與尺度分成不同類型；大質量恆星死亡時可能形成恆星級黑洞；太陽質量不足以變成黑洞，晚期會成為紅巨星，外層散去後留下白矮星。觀測黑洞必須研究其對周圍恆星、氣體與高能光的影響。

## ESA Black Holes
來源：https://www.esa.int/Science_Exploration/Space_Science/Black_holes

ESA 說明黑洞的逃逸速度大於光速，因此連光也無法離開；大質量恆星核心塌縮可能形成黑洞，星系中心通常可見超大質量黑洞。黑洞可藉由吸積物質產生的高能輻射、重力波及重力透鏡等方式間接觀測。ESA 亦指出 2019 年事件視界望遠鏡取得黑洞暗影影像，適合用於「如何知道看不見的天體存在」展項。

## 內容使用原則

天文館採用學生版改寫，不直接複製來源段落；數字與時效性資訊應避免硬編入互動題目，除非標注資料日期。展區將優先呈現可觀察、可比較、可用生活例子理解的概念，並將「已知事實」與「仍在研究的問題」分開標示。
